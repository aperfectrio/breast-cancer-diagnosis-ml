WDBC Classification Project Report

1. Which classifiers did you test?

- SVM (Support Vector Machine)
- Decision Tree
- KNN (K-Nearest Neighbors)
- Random Forest

2. Which classifier gave the best accuracy?

Random Forest gave the best accuracy.

Accuracy = 0.9649 (96.49%)

3. What does the confusion matrix show?

The confusion matrix shows how many samples were correctly and incorrectly classified by the model. It compares the actual labels with the predicted labels.

4. Was the model good at predicting both classes?

Yes. The Random Forest classifier achieved high accuracy and correctly predicted most malignant and benign cases.

5. Why is documentation important in an open-source ML project?

Documentation helps users understand the project, install dependencies, run the code, understand the results, and contribute to the project more easily.
