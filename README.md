# WDBC Classification Project

## Project Purpose
This project uses Machine Learning classification algorithms to predict whether a breast cancer tumor is malignant or benign using the Wisconsin Diagnostic Breast Cancer (WDBC) dataset.

## Dataset Used
Breast Cancer Wisconsin Diagnostic Dataset provided by Scikit-Learn.

## Requirements

Install dependencies:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python wdbc_classification.py
```

## Output Files

- wdbc_classification_matrix.png
- wdbc_classification_scatter.png

## Classifiers Tested

- SVM
- Decision Tree
- KNN
- Random Forest

## Best Classifier

Random Forest

Accuracy: 0.9649 (96.49%)
